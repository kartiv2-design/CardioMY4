# CardioHRV — Android App

Приложение для измерения пульса и вариабельности сердечного ритма (ВСР) через камеру телефона.

## Как собрать

### Требования
- Android Studio Hedgehog (2023.1) или новее
- JDK 17+
- Android SDK (API 24+)

### Шаги
1. Распакуйте ZIP
2. Откройте папку `CardioHRV` в Android Studio (File → Open)
3. Дождитесь синхронизации Gradle
4. Нажмите Run (▶) или Build → Generate APK

## Как пользоваться

1. Приложите подушечку пальца к **задней камере** телефона — вспышка подсветит палец
2. Держите неподвижно 60 секунд
3. Смотрите результаты в реальном времени

## Метрики ВСР
- **RMSSD** — краткосрочная вариабельность (восстановление)
- **SDNN** — общая вариабельность сердечного ритма
- **pNN50** — доля интервалов >50 мс (парасимпатика)
- **Стресс** — индекс Баевского
- **RR** — средний RR-интервал

## Технология
Использует rPPG (Remote Photoplethysmography) — анализ изменений яркости пикселей Y-канала (яркость) для детекции пульсации крови.
